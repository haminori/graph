# depgraph — визуализация графа зависимостей пакетов Cargo

Учебный проект (вариант №19): CLI-инструмент, который строит граф
зависимостей пакета менеджера Cargo (Rust) без использования готовых
менеджеров пакетов и библиотек для получения зависимостей.

Сейчас реализован **этап 1** — минимальный прототип с конфигурацией.

## Общее описание

Приложение читает настройки из CSV-файла, проверяет каждый параметр и
печатает все параметры в формате `ключ = значение`. При ошибках выводится
список всех найденных проблем в stderr, код завершения — `1`.

## Конфигурационный файл

Формат: строки `параметр,значение`. Заголовок `parameter,value`, пустые
строки и BOM допускаются. Пример: `examples/config_remote.csv`.

| Параметр          | Описание                                   | Допустимые значения                                                  |
|-------------------|--------------------------------------------|----------------------------------------------------------------------|
| `package_name`    | Имя анализируемого пакета                  | remote: имя крейта (латиница, цифры, `-`, `_`, до 64 символов); test: заглавные латинские буквы |
| `repository`      | URL репозитория или путь к тестовому файлу | remote: `http(s)://хост/путь`; test: путь к существующему файлу      |
| `repo_mode`       | Режим работы с репозиторием                | `remote` или `test`                                                  |
| `package_version` | Версия пакета                              | SemVer `MAJOR.MINOR.PATCH[-pre][+build]`                             |
| `output_image`    | Имя файла с изображением графа             | имя с расширением `.svg`, каталог должен существовать                |
| `ascii_tree`      | Вывод зависимостей в виде ASCII-дерева     | `true`/`false` (также `yes`/`no`, `1`/`0`, `on`/`off`)               |
| `max_depth`       | Максимальная глубина анализа               | целое число от 1 до 100                                              |

## Обработка ошибок

Проверяются и сообщаются (все сразу, с номерами строк там, где это уместно):
файл не найден, это каталог, нет прав на чтение, пустой файл, не UTF-8,
некорректный CSV, неверное число столбцов, неизвестный или повторяющийся
параметр, отсутствующий параметр, пустое значение и неверное значение
каждого из семи параметров (включая правила режима `test`).

## Запуск

Требуется Python 3.9+. Сторонние библиотеки не нужны.

```sh
./run.sh -c examples/config_remote.csv      # Linux / macOS
run.bat -c examples\config_remote.csv       # Windows
make run CONFIG=examples/config_test.csv    # через Makefile
```

Без `-c` используется `config.csv` в текущем каталоге.

## Тесты

```sh
make test
```

## Примеры использования

```console
$ ./run.sh -c examples/config_remote.csv
package_name = serde
repository = https://github.com/serde-rs/serde
repo_mode = remote
package_version = 1.0.210
output_image = graph.svg
ascii_tree = true
max_depth = 3
```

Демонстрация ошибок для всех параметров (файлы в `examples/errors/`):

```sh
make demo-errors
```

```console
$ ./run.sh -c examples/errors/bad_depth.csv
Ошибка конфигурации:
  - параметр 'max_depth': ожидалось целое число от 1 до 100, получено '-3'
```
